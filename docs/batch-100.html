Choose a Chart, Disclose Missing Rows

An interactive local lab for choosing charts and writing honest captions. No external library or upload.

Comparison, sequence, or relationship?

Bars compare individual records, not grouped region totals. Lines preserve input order, not automatic date sorting. Scatter needs two numeric fields and cannot establish causation. The question selector below explains the valid-record denominator.

Negative and missing values matter

Revenue gives five numeric values from six records; March is missing. May’s −30 adjustment stays below zero. Lines break across excluded records instead of implying continuity. Revenue-versus-orders scatter has four numeric pairs: missing March revenue and text April orders exclude two records.

Constant axes and display limits

Constant numeric X is centered in scatter; all-zero Y still has a usable range. Full-app limits: first 24 valid bars, first 200 line points, first 500 scatter pairs. Disclose truncation; inspect the plotted-data table as a nonvisual alternative.

Write an honest caption

“Synthetic monthly revenue records; five of six values plotted, one missing revenue excluded. May includes a −30 adjustment. File order preserved; no regional aggregation or causal claim.” Add actual units and scope for approved data. Export SVG and inspect before sharing.
