ASF-visualizer / practical guide / November 2026

Choose the chart that answers the question

Bar, line, or scatter—with the limitations visible.

Bar: compare individual records

Bars show the first 24 valid records. They are not grouped totals or category aggregates. Repeated category labels still represent separate records. Choose a numeric Y field and inspect the underlying table before comparing values.

Line: inspect input order

Lines show the first 200 valid records in input order. They do not automatically sort dates or establish equal time intervals. Prepare correctly ordered input for a time-series question. A line between two points is not a prediction.

Scatter: compare numeric pairs

Scatter plots need numeric X and Y fields and show up to 500 valid pairs. Missing and nonnumeric pairs are excluded. Association is not causation, and a display limit is not a representative sampling guarantee.

Read the status and accessible table

The chart status reports plotted, excluded and limited records. Y axes include zero; negative values are supported. Hover for values or expand Inspect plotted data to read the same points as a table. Use Analytics to review the full dataset's completeness and summaries.

Export without an upload

Export SVG chart downloads the current chart locally. Export dataset CSV includes the full current dataset, not just plotted points. Review both before sharing. A static SVG contains the plotted labels and values.

Try a defensible comparison

  1. Open Visualizer and use the synthetic sample.
  2. Compare a monthly bar chart with a line chart in the sample's input order.
  3. Use orders and revenue for a scatter plot.
  4. Inspect plotted records, then export the SVG.
